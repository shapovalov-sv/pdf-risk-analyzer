# PDF Risk Analyzer v4

Офлайн-инструмент для анализа рисков в PDF-документах. Работает полностью в браузере — документы не покидают устройство.

## Возможности

- **Пакетная обработка** — загрузка и анализ нескольких PDF одновременно
- **8 категорий рисков**: судимости, административные нарушения, ФССП/исполнительные производства, банкротство, розыск, экстремизм/санкции, кредитная история, налоговые нарушения
- **Цветовой анализ** — определение красных выделений в PDF
- **Переход к фрагменту** — клик по совпадению открывает нужную страницу с подсветкой
- **Извлечение данных** — суммы, статьи УК/КоАП, номера ИП, ИНН, ОГРН, даты
- **Умное отрицание** — фразы «не судим», «отсутствие задолженности» снижают риск
- **Итоговая таблица** по всем файлам с баллом риска и ФИО субъекта

## Использование

Откройте `risk_analyzer_v4.html` в браузере — никаких серверов, зависимостей и установок.

## Стек

Чистый HTML/CSS/JS + [PDF.js](https://mozilla.github.io/pdf.js/) (CDN)
