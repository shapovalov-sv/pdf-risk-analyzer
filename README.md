# PDF Risk Analyzer v8.0

Офлайн-инструмент для анализа PDF-отчётов (HimeraSearch и аналоги) по физическому лицу.
Работает **полностью в браузере** — документы не покидают устройство. Один самодостаточный
HTML-файл, без сервера и установки.

## Ключевые возможности

- **Две независимые шкалы 0–100**:
  - **Риск-балл** — негатив (судимость, долги, розыск, банкротство…)
  - **Факторы стабильности** — плюсы (семья, имущество, работа, банки, регистрация в РФ)
- **11 категорий риска** с прозрачным разбором «из чего сложился балл»
- **Насыщение и пороги тяжести** — подтверждённая судимость ⇒ как минимум высокий риск;
  эскалация за совокупность драйверов стремит балл к 100
- **Детальные таблицы** исполнительных производств (ФССП) и заявок на микрозаймы — с суммами,
  статусами и итогами (отказы по займам не считаются взятыми)
- **Переход к источнику** — клик по совпадению, строке ИП/микрозайма или фактору стабильности
  открывает нужную страницу PDF с подсветкой
- **Извлечение данных** — суммы, статьи УК/КоАП, номера ИП, ИНН, ОГРН, даты, карточка субъекта
- **Умный отсев ложных срабатываний** — отрицания («не судим», «не женат»), погашенное,
  цитирование закона, чужое ФИО, «хищение» при утрате документа, метки-поля и др.
- **Цветовой анализ** — распознавание красных выделений в PDF
- **Пакетная обработка** + сводная таблица по всем файлам

📄 **Полный обзор всех функций — в [FEATURES.md](FEATURES.md).**

## Использование

Откройте `risk_analyzer_v8.html` в браузере — никаких серверов, зависимостей и установок.
Перетащите один или несколько `.pdf` (или `.txt`) и нажмите «Анализировать».

## Стек

Чистый HTML/CSS/JS + [PDF.js](https://mozilla.github.io/pdf.js/) (CDN). Регулярные выражения
кешируются при загрузке; обработка PDF и извлечение текста с координатами — в браузере.
